# Категоризатор товаров (Электрика)

Проект автоматически определяет категорию электротовара по одному названию. Например: по строке *«Светильник Nowodvorski Silicone black [6404]»* модель выдаёт категорию *«Светильники, люстры, бра»*. Это нужно, чтобы массово проставлять категории в каталоге без ручной разметки.

Работать с категоризатором можно двумя способами:

1. **В Jupyter** — обучить модель на своих данных и прогнать предсказания в ноутбуке.
2. **Через Telegram-бота** — отправить боту CSV-файл с колонкой «title», получить обратно CSV с колонками категории и статуса.

---

## Что здесь лежит и зачем

| Папка / файл | Назначение |
|--------------|------------|
| **categorizer.ipynb** | Ноутбук: загрузка данных, обучение модели, сохранение в `models/`. Запускай его, если хочешь переобучить модель на своих данных. |
| **inference.py** | Код предсказания: загрузка модели из `models/`, функция `predict_smart()`. Его используют и бот, и при желании — ноутбук. |
| **telegram_bot.py** | Telegram-бот: принимает CSV, вызывает модель, отдаёт результат CSV. Запускается отдельным процессом. |
| **models/** | Здесь лежат обученная модель (`model.joblib`), список категорий (`labels.json`), метрики (`metrics.json`) и множество «уже виденных» названий (`seen_titles`). Без этой папки бот не запустится — сначала нужно обучить модель в ноутбуке. |
| **data/raw/products.csv** | Исходные данные для обучения: пары «название — категория». |
| **data/import.csv** | Пример входящего файла для бота: одна колонка `title`. |
| **data/categorized.csv** | Пример результата: `title`, `pred_status`, `pred_category`, `pred_message`. |
| **.env** | Секреты: токен бота `TELEGRAM_BOT_TOKEN`. Файл не коммитится в git. |
| **.env.example** | Шаблон: какие переменные задать (без реального токена). |

Модель — это пайплайн: TF-IDF по словам и символам + LinearSVC с калибровкой. Обучается только на названиях, без описаний и картинок. Если название не встречалось в обучающей выборке или модель не уверена, в результате будет статус «без категории» и сообщение (например, «title not in training set» или «Low confidence»).

## Как запускать на Windows 11

### 1. Установить Python

Нужен Python 3.10 или новее. Скачай установщик с [python.org](https://www.python.org/downloads/) и при установке отметь **«Add Python to PATH»**.

Проверка в терминале (PowerShell или cmd):

```text
python --version
```

Должно быть что-то вроде `Python 3.12.x`.

### 2. Открыть папку проекта в терминале

Например:

```text
cd C:\Users\ТвойПользователь\Documents\dev\yana\category_finder
```

(подставь свой путь к папке `category_finder`).

### 3. Создать виртуальное окружение и установить зависимости

```text
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

После `activate` в начале строки должно появиться `(.venv)`.

**Важно:** Если ранее был установлен пакет `telegram` (не `python-telegram-bot`), его нужно удалить:
```text
pip uninstall telegram
pip install python-telegram-bot>=22.6
```

### 4. Настроить токен бота

Создай в папке проекта файл **.env** (без имени перед точкой, расширение `.env`). Внутри одна строка:

```text
TELEGRAM_BOT_TOKEN=твой_токен_от_BotFather
```

Токен получаешь в Telegram у [@BotFather](https://t.me/BotFather): команда `/newbot` или `/mybots` → API Token. В репозиторий и в чаты токен не вставляй.

### 5. Запустить бота

Убедись, что виртуальное окружение включено (видишь `(.venv)`), и выполни:

```text
python telegram_bot.py
```

В консоли появится что-то вроде:
- `Model loaded.`
- `Bot started. Waiting for updates...`
- `Send /start to your bot in Telegram to test it.`

Бот работает. Остановить: `Ctrl+C` или закройте окно терминала.

Дальше в Telegram: найди своего бота, отправь `/start`, затем отправь файл **.csv** с колонкой **title** (или «название»). Бот вернёт файл с колонками `title`, `pred_status`, `pred_category`, `pred_message`.

**Примечание:** Обработка файлов выполняется асинхронно в отдельном потоке, чтобы бот не зависал во время работы модели. Для больших файлов обработка может занять некоторое время.

## Весь процесс работы (от данных до результата)

### Обучение модели (один раз или при обновлении данных)

1. Положи в **data/raw/** CSV с колонками **category** и **title** (разделитель `;`, кодировка cp1251 или UTF-8 — ноутбук попробует сам).
2. Открой **categorizer.ipynb** в Jupyter (или в VS Code / Cursor с поддержкой ноутбуков).
3. Прогони ячейки по порядку: загрузка данных → проверка → препроцессинг → разбиение на train/val/test → обучение → сохранение артефактов в **models/**.
4. В **models/** появятся `model.joblib`, `labels.json`, `metrics.json` и при сохранении — список «уже виденных» названий. С этого момента бот может использовать эту модель.

### Работа через бота (каждый раз)

1. Пользователь открывает бота в Telegram.
2. Отправляет команду **/start** — бот пишет, что нужно отправить CSV с колонкой «title».
3. Отправляет файл **.csv**: одна колонка с названиями товаров (заголовок «title» или «название», либо первая колонка).
4. Бот:
   - скачивает файл;
   - читает названия (поддерживаются кодировки UTF-8, UTF-8-sig и CP1251);
   - обрабатывает названия через модель (выполняется асинхронно в отдельном потоке);
   - собирает результат: для каждой строки — статус (OK или «без категории»), предсказанная категория, пояснение (уверенность или причина отказа).
5. Бот отправляет обратно CSV с колонками: **title**, **pred_status**, **pred_category**, **pred_message**.
6. Пользователь сохраняет файл и при необходимости доразмечает вручную строки со статусом «без категории».

Ограничения бота (чтобы не упираться в таймауты и память): размер файла до **15 МБ**, количество строк до **5000**. При необходимости лимиты можно поменять в `telegram_bot.py` (константы `MAX_FILE_SIZE_MB` и `MAX_ROWS`).

## Если папки models/ нет или бот ругается

Бот не умеет обучать модель — он только загружает её из **models/**. Если папки нет или в ней нет `model.joblib` и `labels.json`, нужно один раз обучить модель в ноутбуке **categorizer.ipynb** и сохранить артефакты (в ноутбуке есть ячейка с `save_artifacts(...)`). После этого снова запусти `python telegram_bot.py`.

## Возможные проблемы

### Ошибка "ModuleNotFoundError: No module named 'telegram.ext'"

Это означает, что установлен неправильный пакет `telegram` вместо `python-telegram-bot`. Решение:
```text
pip uninstall telegram
pip install python-telegram-bot>=22.6
```

### Бот не отвечает после "Обрабатываю X названий…"

В текущей версии эта проблема исправлена: обработка выполняется асинхронно в отдельном потоке. Если проблема повторяется, проверьте логи в консоли — там будет информация о том, на каком этапе происходит ошибка.
